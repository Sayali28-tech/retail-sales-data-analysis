
# Retail Sales Data Analysis

## 📌 Project Overview

This project focuses on analyzing retail transaction data to identify sales trends, customer purchasing behavior, and product performance using Python.

The objective is to transform raw retail data into meaningful business insights that can help businesses understand revenue patterns, identify valuable customers, and make data-driven decisions.

## 🎯 Business Objectives

- Analyze overall retail sales and revenue trends.
- Identify monthly revenue patterns and growth.
- Understand customer purchasing behavior.
- Identify the top 10 customers by revenue.
- Analyze product performance and identify top-selling products.
- Generate actionable business recommendations.

## 🛠️ Tools and Technologies

- **Python** – Data analysis
- **Pandas** – Data cleaning and manipulation
- **Jupyter Notebook** – Analysis and documentation
- **Matplotlib / Seaborn** – Data visualization (if used)
- **SQL** – Optional additional analysis, if used

## 📂 Dataset

**Dataset:** Online Retail Dataset

**Source:** [UCI Machine Learning Repository – Online Retail](https://archive.ics.uci.edu/dataset/352/online+retail)

The dataset contains transactions from a UK-based online retailer between December 2010 and December 2011.

### Key Columns

| Column | Description |
|---|---|
| InvoiceNo | Invoice number for each transaction |
| StockCode | Unique product code |
| Description | Product description |
| Quantity | Number of units purchased |
| InvoiceDate | Date and time of the transaction |
| UnitPrice | Price per unit |
| CustomerID | Customer identifier |
| Country | Customer's country |

## 🔄 Project Workflow

1. **Data Loading:** Imported the retail dataset into Python using Pandas.
2. **Data Exploration:** Examined the dataset structure, columns, and data types.
3. **Data Cleaning:** Investigated missing values, duplicate records, and data quality issues.
4. **Data Preparation:** Prepared the data for analysis using appropriate cleaning rules.
5. **Revenue Analysis:** Calculated revenue and analyzed monthly sales trends.
6. **Customer Analysis:** Identified high-value customers and analyzed repeat purchasing behavior.
7. **Product Analysis:** Evaluated product performance based on revenue.
8. **Business Insights:** Summarized findings and developed recommendations.

## 📊 Key Findings

The analysis produced the following results:

- **Revenue from identifiable customers:** £8,887,208.89
- **Revenue generated by the top 10 customers:** £1,537,659.21
- **Revenue share of the top 10 customers:** 17.3%

### Additional Insights

- **Monthly Revenue:** Analyzed monthly revenue to identify seasonal patterns and changes in sales performance.
- **Customer Behavior:** Examined repeat purchases and customer contribution to revenue.
- **Product Performance:** Evaluated products based on their revenue contribution.
- **Data Quality:** Investigated missing customer identifiers and duplicate transaction records.

*Note: Revenue figures depend on the data-cleaning rules and transaction filters used. Customer-level revenue excludes transactions without an identifiable CustomerID. Additional insights should be supported by the corresponding notebook calculations.*

## 💡 Business Recommendations

Based on the analysis, the following actions could help improve business performance:

- **Customer Retention:** Introduce loyalty programs and personalized offers to encourage repeat purchases.
- **Revenue Monitoring:** Track monthly revenue to identify seasonal patterns and changes in performance.
- **Customer Segmentation:** Identify high-value customers and develop targeted marketing strategies.
- **Product Strategy:** Use product revenue analysis to guide promotions and cross-selling opportunities.
- **Data Quality:** Improve customer identification and transaction data quality to support more reliable analysis.

## ⚠️ Limitations

- Some transactions have missing customer identifiers.
- The dataset covers a historical period rather than current retail activity.
- Revenue calculations can vary depending on the treatment of cancellations, returns, and invalid transactions.
- Historical trends may not predict future sales performance.
